# Skill: feature-planning

Usar antes de desarrollar cualquier funcionalidad de tamaño medio/grande.

1. Inspeccionar la arquitectura y el código existente relacionado.
2. Identificar qué archivos se van a ver afectados.
3. Detectar riesgos (seguridad, datos, compatibilidad con lo ya construido).
4. Proponer un plan concreto antes de tocar código.
5. Si hay una decisión de producto importante involucrada, pedir confirmación al
   dueño del proyecto antes de implementar.
6. Implementar por etapas chicas y verificables.
7. Probar cada etapa.
8. Actualizar la documentación relevante en docs/.
